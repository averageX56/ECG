# Поиск современных решений и новые эксперименты — 2026-09-05

## Что изучено

- [Self-ONN + temporal feature injection](https://arxiv.org/abs/2204.03768): компактное объединение морфологии и RR. Основание для расширения временного контекста, не точная репликация архитектуры.
- [Visibility graphs + GCN, 2024](https://arxiv.org/abs/2404.15367): авторы отмечают сохраняющуюся сложность S-класса при inter-patient проверке. Само усложнение архитектуры не гарантирует решения.
- [TolerantECG, 2025](https://arxiv.org/html/2507.09887v1): contrastive signal/report alignment и distillation для шума/пропущенных отведений. Кандидат для дальнейшего переноса; здесь веса не запускались, SOTA не воспроизведено.
- [ECGFounder, официальный код](https://github.com/NickLJLee/ECGFounder): доступны предобученные модели; авторы требуют соблюдения собственной предобработки. Перед переносом необходимы проверка состава pretraining и соответствия задач/отведений. Здесь модель ещё не запускалась.
- [PhysioNet Challenge 2015](https://physionet.org/content/challenge-2015/1.0.0/): проверяет истинность тревог, в том числе ЖТ, с несколькими сигналами. Это отличается от непрерывного поиска ≥3 V в MIT-BIH; результаты напрямую несопоставимы.

## Реально выполнено

Четыре HGB ablation, 150 итераций, фиксированный seed42. Контекст RR на 11/51/201 сокращениях, признаки шести соседних сокращений, нормированная морфология и отклонение от медианного шаблона записи. Метки соседей не используются. Три схемы весов: inverse frequency, square root, natural. Четвёртая проба — прежние signal+interval признаки со square-root весами.

Скрипт открывает только train/valid NPZ. Уже просмотренный test не использован повторно. Все результаты ниже — validation, четыре записи; это поиск гипотез, не независимое подтверждение обобщения. Временной контекст офлайн.

| Вариант | S end-to-end F1 | V end-to-end F1 |
|---|---:|---:|
| Предыдущая fusion | 0.303 | 0.637 |
| Context balanced | 0.461 | 0.573 |
| Context sqrt | 0.432 | 0.600 |
| Context natural | 0.386 | 0.627 |
| Fusion sqrt | 0.172 | 0.633 |

Лучший новый macro F1 N/S/V/F ≈0.495. Прирост S не универсален: на записи207 F1 S остаётся нулевым. Есть компромисс с V. Новые модели сохранены отдельно, действующий CLI не переключён автоматически.

Проверены фиксированные VT-правила при score≥0.5 и ≥0.8, ≥3 последовательных V, частота≥100. Из 9 validation эпизодов прежняя fusion находит 2 при0.5 (12 кандидатов, один без пересечения) против1 при0.8. Новые модели не улучшают полноту. Несколько кандидатов внутри одного эпизода не считаются несколькими найденными эпизодами. Границы и клиническая специфичность этим не подтверждены.

## Воспроизведение и артефакты

```powershell
python -m ecg_project.experiments.context_experiments
python scripts/evaluate_context_vt.py
python -m pytest -q
```

`artifacts/context_experiments/`: четыре модели, per-record validation metrics, selection и budget. Обучение/оценка этого запуска 66.97с. `reports/context_vt_validation.json`: сравнение правил. Тесты:20 passed; тест короткой записи выявил падение native median filter при окне намного длиннее входа, исправлено явным edge padding.

## Следующие гипотезы

1. Sequence encoder на нескольких сокращениях с отдельными rhythm/morphology ветвями; сравнивать с context HGB, а не только со слабым CNN.
2. Разобрать пропуски на207: отдельно детекция, V/S путаница, специфичная морфология, короткие VT. Требуется анализ validation событий, а не снижение порога по test.
3. Проверить доступность и pretraining provenance ECGFounder/TolerantECG, затем frozen embeddings/малый adapter в оставшемся бюджете.
4. Для переноса результатов на новые источники нужна новая независимая проверка: существующий test уже просмотрен в первом цикле разработки.
