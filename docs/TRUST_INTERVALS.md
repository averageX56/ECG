# Непрерывные области уверенности P/QRS/T

Дополнительная ячейка в конце `04_all_pipelines_a100.ipynb`: включите
`RUN_TRUST_INTERVALS = True`. Существующая ячейка классификатора остаётся отдельной.

Вероятности четырёх классов сглаживаются скользящим средним по 20 мс.
Для каждой волны выделяется непрерывная область, где её класс выигрывает argmax
и вероятность не ниже `uncertainty_threshold=0.30`. Внутри требуется уверенное
ядро с вероятностью >= `confidence_threshold=0.50` длиной хотя бы 5 отсчётов
при 250 Гц. Несколько уверенных фрагментов внутри одной области объединяются
в один интервал от первого до последнего; внутренние провалы не создают «пианино».
Края расширяются максимум на `max_extension_ms=40` каждый относительно ядра.
Фон класса 0 после сглаживания и соседние классы останавливают область;
отдельные неуверенные островки без ядра не становятся волнами.

Для начала волны сохраняется диапазон `[внешнее начало, начало ядра]`, для конца —
`[конец ядра, внешний конец]`. Из них вычисляются нижняя/верхняя границы QRS, PR,
QT, T и относительной ширины QRS. Например, минимальная QRS-длительность — ширина
ядра, максимальная — ширина внешней области. PR использует диапазоны начала P и QRS.
Ассоциация P/QRS/T фиксирована по ядрам; этот эксперимент не моделирует неопределённость
выбора соседней волны. Недетектированная P отмечается как неизвестная.

Каждая фича поступает как точечное значение, нижняя граница, верхняя граница,
ширина диапазона и уверенность (минимум средних вероятностей участвующих волн).
Всего 65 значений + 65 масок отсутствия. Для RR и морфологии границы совпадают
с точечной оценкой, уверенность разметчика неприменима и отмечена как отсутствующая.
R-пики и waveform crops сохраняются одинаковыми с исходным экспериментом.
Это диапазоны из softmax-вероятностей, а не статистические интервалы с гарантией покрытия.

Четыре варианта: `unet/point`, `unet/trust`, `qwen/point`, `qwen/trust`.
Контроль `point` использует те же ядра, записи, классы, разбиения и пропуски,
но без дополнительных границ и уверенности. Выбор модели — по validation AUROC,
пороги болезней — по validation F1. Параметры границ фиксируются до эксперимента;
при переборе выбирайте их по validation, не по test/external.

По умолчанию результаты пишутся в `<classifier_cfg.output>_trust`:

- `inputs/{unet,qwen}`: новые признаки и волны с границами;
- `point_inputs/{unet,qwen}`: контрольные признаки;
- `{point,trust}/common_diagnoses_v1/{unet,qwen}/best.pt`: модели и настройки границ;
- `comparison.csv/json`: сравнение по когортам;
- `feature_coverage.csv`: доля доступных фичей и средняя ширина диапазонов по источникам.

Старый кеш проверяется и используется для сопоставления записей. Для новых границ
нужен один дополнительный проход каждого разметчика: в старом кеше нет softmax-областей.
Новые shards возобновляются по хешам. Смена параметров требует нового `TRUST_OUTPUT`.
`ClassificationPredictor` читает настройки из checkpoint и применяет тот же способ
разметки к новым записям. Полный запуск требует обученных разметчиков на кластере.
