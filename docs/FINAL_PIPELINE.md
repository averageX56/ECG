# Исторически выбранный финальный ECG-пайплайн

Обученные веса и отчёты прогонов удалены по последнему запросу. Ниже зафиксирован прежний выбор; для повторного запуска требуется обучение по [FRESH_START.md](FRESH_START.md).

Запуск: `python -m pipelines.cpu.run run LUDB/1.hea --output reports/final_example`.
Единый notebook: `notebooks/04_all_pipelines_a100.ipynb`. Разделение локальной подготовки и кластера: [pipelines](../pipelines/README.md).

## Выбранный маршрут

1. Чтение WFDB/CSV с учётом fs, отведений и доступной калибровки; обработка сигнала и детекция сокращений.
2. U-Net, обученный на LUDB и адаптированный на QT: границы P/QRS/T по отведениям, интервалы, нарезанные сокращения. QRS ≥120 мс маркируется как широкий.
3. Интервальные признаки → HGB для многометочной классификации 12-канальных записей. Validation PTB fold9 macro AUROC **0.9044** против **0.9023** у fusion.
4. Нарезанные сокращения и интервалы → scratch Beat-BERT для N/S/V/F: validation end-to-end macro F1 **0.5621**, S **0.4366**, V **0.7005**. Fusion baseline: macro F1 **0.4741**. Ошибки детекции учитываются.
5. Отдельная фиксированная fusion-голова формирует кандидаты ЖТ: при пороге 0.8 найдён **1 из 9** validation-эпизодов, у BERT — **0 из 9**. Этот этап оставлен ради эпизодной задачи; низкая полнота не позволяет считать ЖТ решённой.

Это один маршрут с головами для разных задач, без автоматического переключения на новые экспериментальные веса. Пути и SHA256 четырёх моделей закреплены в [configs/final_pipeline.json](../configs/final_pipeline.json); при подмене артефакта запуск прерывается. Веса не хранятся в Git и переносятся отдельно с сохранением путей.

Ранее измеренные LUDB test F1 P/QRS/T: **0.9706/0.9969/0.9846**, MAE ширины QRS **10.914 мс**. Эти test-результаты уже просмотрены в разработке; новый независимый контроль они не заменяют. Выбор классификаторов выполнен по validation, а smoke проверяет только исполнимость. Исходные отчёты этого сравнения удалены при очистке; эти значения сохранены только как историческое описание выбора, а не как результаты нового запуска.

## Выход и границы применимости

`intervals_predicted.csv`, `beats.npz`, `beat_classification.csv`, `analysis.json` и `delineation.png` содержат границы, длительности, типы сокращений, оценки заболеваний, кандидаты ЖТ и происхождение моделей. Ручная разметка выводится отдельно, в признаки не подмешивается.

ЖЭС/НадЖЭС оцениваются по сигналу и временным признакам; один широкий QRS не определяет диагноз. Перенос beat-классификатора с MIT MLII на другие отведения не подтверждён. Форма ФП (впервые выявленная/постоянная) остаётся неизвестной без анамнеза. Редкие АВ-блокады II/III степени недостаточно валидированы; длительность QRS не определяет клиническую критичность блокады. Поддержка входного формата не равна доказанному качеству на каждом датасете.

HuBERT-ECG Large + LoRA сохранён как опциональная исследовательская ветвь общего ноутбука. Он не выбран вместо HGB: PTB/CPSC/Georgia присутствовали в его предобучении, а локальный smoke не доказывает преимущество. Обучение на A100 и сравнение frozen/LoRA используют только train/valid, без fold10.
