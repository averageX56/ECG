# Консольный запуск Qwen 1.7B и всех классификаторов

Из корня ECG в окружении кластера:

```bash
python -u scripts/train_classifiers.py
```

Последовательность по умолчанию:

1. Новые адаптер и голова **Qwen3-1.7B, NF4 QLoRA** поверх официальной базовой модели.
   Две эпохи разогрева на готовой чистой ручной разметке LUDB + QTDB. Checkpoint 4B не используется.
2. Эксперимент E с лучшими весами разогрева: полная эпоха по всем окнам существующего
   `artifacts/qwen_pseudo_extended`, ручные батчи повторяются, hard CE + soft KD.
   До 20 эпох, patience 5, LR 5e-5, отношение manual:pseudo 1:4.
3. Один проход нового Qwen для новых интервалов, границ и мягких масок.
   Выбор записей, R-пики и crops проверяются на совпадение с прежним кешем классификатора.
4. Классификаторы: waveform; ECG + исходные интервалы U-Net/Qwen; point control;
   границы уверенности; границы + мягкие временные маски. Всего девять веток.

CPU-пайплайн и генератор псевдометок не запускаются. Готовые U-Net кеши и обученные
классификаторы переиспользуются. Если отсутствуют U-Net границы/маски, рассчитываются
только недостающие этапы из существующих исходных записей. Для **нового Qwen** фичи
нужно вычислить заново: старые признаки 4B не относятся к новой модели.
База Qwen3-1.7B при отсутствии скачивается существующим `download_qwen.py`.
Полный псевдопроход означает все окна обучающего кеша, а не новые записи или новые
участки длинных ЭКГ. Protected holdouts и ручная validation сохраняются.

Классификаторы: остановка после пяти эпох без накопленного улучшения validation AUROC
больше 0.001. При этом `best.pt` сохраняет фактический максимум AUROC, даже если
улучшение меньше min-delta. Политика остановки пересчитывается из истории при resume,
поэтому применима к старым прерванным запускам. Максимум эпох и scheduler старого run
сохраняются. Завершённые ветки не переобучаются.

```bash
# Проверка плана без скачивания, изменения файлов и обучения:
python scripts/train_classifiers.py --dry-run

# Изменить остановку классификаторов:
python -u scripts/train_classifiers.py --patience 4 --min-delta 0.002

# Ограничить сравнение выбранными этапами:
python -u scripts/train_classifiers.py --stages waveform intervals masks

# Только уже подготовленные классификаторы, без нового Qwen и новой разметки:
python -u scripts/train_classifiers.py --cache-only
```

Пути прежних экспериментов задаются `--base-output`, `--trust-output`, `--masks-output`.
Пути ручного/псевдо кешей — `--manual-root`, `--pseudo-root`; 1.7B базы —
`--qwen-model-root`. Настройки модели: `--qwen-batch-size 16 --qwen-accumulation 4`,
`--warmup-epochs 2 --qwen-epochs 20 --qwen-patience 5`.
Полный список: `python scripts/train_classifiers.py --help`.

Новые веса Qwen: `artifacts/cluster/qwen_1.7b_E_fresh_full_cache`
и соседняя папка `_manual_warmup`. Новые классификаторы Qwen:
`<base-output>_qwen17_fresh_E` и `<base-output>_qwen17_fresh_E_trust_masks`.
Повторный запуск продолжает эти новые runs, а не создаёт ещё один разогрев.
Старые Qwen-классификаторы исключены из обычного запуска; доступны только в `--cache-only`.

Общий отчёт — `reports/classifier_console.json` (можно изменить через `--report`),
метрики и checkpoints каждой ветки остаются в её папке.
В режиме `--cache-only` отсутствующие кеши перечисляются явно; доступные ветки
обрабатываются, код возврата 2 сообщает о незавершённых этапах.
Полное обучение проверяется запуском на GPU кластера; локальные тесты используют
маленькие модели и искусственные данные.
