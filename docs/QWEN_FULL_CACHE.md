# Эксперимент E: весь готовый кеш псевдометок за эпоху

В конце `notebooks/04_all_pipelines_a100.ipynb` добавлена ячейка
`Qwen E: full pass over the existing pseudo cache`.
После настройки окружения включите `RUN_QWEN_E_FULL_CACHE = True` и выполните
именно эту ячейку. Предыдущие ячейки подготовки и обучения выполнять не нужно.

`E_EXISTING_RUN` берётся из `classifier_cfg.qwen_run` или конфигурации классификатора.
Из curriculum выбирается принятый checkpoint. Архитектура, базовая модель,
ручной кеш и кеш псевдометок наследуются из его `config.json`.
Новый запуск сохраняется в `<E_EXISTING_RUN>_full_cache_E`; старые веса сохраняются.
Оптимизатор запускается заново; повторный запуск новой ячейки возобновляет новый run.

Ранее эпоха содержала столько шагов, сколько батчей в ручной выборке. При отношении
1:4 это позволяло увидеть лишь четыре псевдо-батча на один ручной, даже если кеш
псевдометок гораздо больше. В режиме `pseudo_full_pass=True` число шагов равно
`max(manual_batches, ceil(pseudo_batches / pseudo_per_manual))`.
Ручной DataLoader повторяется; перемешанный псевдо-DataLoader проходит ровно один
раз без повторов, включая неполный последний батч. Все окна кеша участвуют в soft KD;
hard CE сохраняет прежний порог уверенности. Маски валидности продолжают действовать.

Настройки нового запуска: отношение 1:4, learning rate `5e-5`, максимум 20 полных
эпох, patience 5, без `max_batches` и `valid_limit`. Loss weights эксперимента E
наследуются из исходного запуска. Модель выбирается по прежней ручной validation.
Число эпох здесь нельзя напрямую сравнивать с предыдущим curriculum: каждая эпоха
теперь существенно длиннее. В `history.json` сохраняются `pseudo_examples_seen`
и `manual_examples_seen`; полнота прохода проверяется во время обучения.

CPU pipeline, генерация псевдометок и скачивание модели не вызываются.
Проверки целостности готовых файлов остаются. Используются все окна существующего
**обучающего** кеша: новые датасеты и дополнительные части длинных записей сами не
появляются. В текущем подготовителе псевдометок используется первое 10-секундное окно
допущенных записей. Validation/test и protected registry не переводятся в train.

Для запуска из Python:

```python
from pipelines.gpu.experiments import full_cached_e, run_qwen

cfg = full_cached_e('artifacts/cluster/qwen_4b_E_curriculum')
run_qwen(cfg, run_smoke=False)
```

Если пути перемещены, `full_cached_e` принимает `pseudo_root` и `model_root`.
Параметры обучения можно изменить через `dataclasses.replace` до первого запуска.
Для классификации с новым разметчиком затем задайте его новый `qwen_run` и новый
`output`: признаки старого разметчика нельзя выдавать за признаки нового.
